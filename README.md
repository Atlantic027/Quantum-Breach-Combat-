# 量子突破：战斗模式 · Quantum Breach: Combat

> 单文件 HTML5 弹幕生存射击游戏 · 零依赖 · 打开即玩

在量子维度之间穿梭，用相位标记引爆整片敌潮，每一次升级都让你更接近那个跨维度 BOSS。

---

## 玩法简介

这是一个俯视角弹幕射击（arena shooter）小游戏。你要在 α / β 两个量子维度之间反复切换，在规避弹幕的同时给敌人叠加**相位标记**，再一次性引爆清场。

- **维度机制**：空格键切换维度并引爆所有标记。引爆会清除附近敌方弹幕、带来短暂无敌，并在切换后获得 **2 秒火力超载**；异维度敌人可见但无法被直接命中，而 BOSS 始终存在于所有维度。
- **成长循环**：击杀敌人获得经验 → 升级 → 三选一永久强化。每次升级回复 15 点生命并获得短暂护盾。
- **BOSS 战**：每 5 级迎战跨维度 BOSS，难度逐级提升。

## 操作方式

| 按键 | 动作 |
| --- | --- |
| `WASD` | 移动 |
| 鼠标 | 瞄准 |
| 鼠标左键（按住） | 射击（叠加相位标记） |
| `空格` | 切换维度 / 引爆标记 |
| `X` | 相位冲刺 |
| `E` | 维度新星（需升级解锁） |
| `Esc` | 暂停 |

## 强化技能

击杀升级后从随机三项中选择一项永久强化：

| 技能 | 效果 |
| --- | --- |
| 火力强化 | 基础伤害 +35% |
| 超载射击 | 射击间隔缩短（最低 4 帧） |
| 巨型弹体 | 弹体半径 +3，基础伤害 +12% |
| 相位推进 | 冲刺冷却缩短 |
| 脉冲共鸣 | 引爆伤害提升、脉冲范围 +30 |
| 裂变散射 | 每级增加两发散射，最多 6 发 |
| 维度新星 | 解锁 / 强化 E 键跨维度范围攻击，冷却 6 秒 |

## 技术说明

- 纯原生 HTML5 Canvas + Vanilla JS，无框架、无构建步骤、无外部资源
- 固定时间步长（60 FPS）游戏循环，适配窗口缩放
- 赛博故障风（glitch）UI，青色 α / 品红 β 维度视觉区分
